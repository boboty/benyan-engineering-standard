# BenYan Engineering Standard

版本：v1.0.0。本仓库是 BenYan Demo、原型与初始产品的通用工程规范权威来源。按需求使用，不要求每个项目拥有所有层。

```text
BenYan Engineering Standard
          ↓
BenYan Starter Template
          ↓
具体项目
          ↓
项目 AGENTS.md
```

通用规范提供默认值。项目 `AGENTS.md` 可以针对具体项目显式覆盖通用规范；冲突时以其中明确写出的项目级规则为准。偏离默认规范须记录工程理由。

从 [原则](standards/00-principles.md) 开始；新项目参见 [采用指南](docs/adoption.md)。UI 的唯一权威来源是本仓库 `design-system/` 内的 BenYan AI Design System。完整目录见 `standards/`、`templates/` 和 `checklists/`。
