# 独立复核

适用于项目要求第二视角验收、发布前复核或高风险改动。复核机制可以由人员、CI、测试环境或其他独立流程承担，本清单不规定 Agent 角色或调度方式。

- [ ] 复核者或复核流程没有直接参与本次实现，能够形成独立判断
- [ ] 复核对象对应明确的交付版本，复核期间交付内容保持稳定
- [ ] 逐项对照需求、范围和验收标准检查完整 diff、相关代码和测试证据
- [ ] 自动检查的原始结果可复查
- [ ] 适用时实际验证 API、浏览器、数据库、migration、部署或运行边界
- [ ] 沿真实业务链路检查测试路径，评估 mock、手工构造和同源假设是否绕过核心风险
- [ ] 检查边界条件、错误处理、日志、敏感信息、兼容性及范围外改动
- [ ] 未运行、失败或跳过的检查逐项说明原因、影响和处理结论
- [ ] 记录已验证内容、未验证内容、限制和剩余风险
- [ ] 复核不夹带实现修改；发现问题后回到实现阶段修正，再重新复核变化后的交付
