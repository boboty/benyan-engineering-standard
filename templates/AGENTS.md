# 项目规则模板

先读现有实现；使用本项目技术栈与已定义的质量门禁（若项目提供 `make check` 则使用它）。按业务复杂度建立层次，不创建无意义抽象。存在 UI 时使用 BenYan AI Design System。例外及理由写在本文件。

完成后提供实际验证证据：适用的测试、lint、类型检查、构建、migration、接口 / UI / 数据库验证，以及未运行、失败或跳过检查的原因和影响。检查完整 diff、日志、临时代码、Secret 和必要文档。

本文件只承载项目级工程规则。若项目采用 Agent、自动化调度或独立协作工作流，应引用对应的独立流程规范；不要在本文件复制另一套角色、状态和验收协议。
